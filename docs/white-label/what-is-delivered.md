# What is delivered

Strata Storage ships one group, the npm package, so a licence covers all of it.

| Part | What you get under your name |
|---|---|
| Package | Your package name and scope, README and changelog. The core keeps zero runtime dependencies. |
| Entry points | The `react`, `vue`, `angular`, `capacitor` and `firebase` sub-paths the package ships today, renamed under your package. |
| Native plugin | The Capacitor plugin for iOS and Android, with the pod and Android module renamed to match. |
| CLI | The `configure` command under your command name. |
| Docs | These guides and the API reference, rebuilt with your name, package name and colours, on the domain you give us. |
| Licence file | A file on your docs domain naming your licence key, so anyone can [verify it](./verify-a-licence.md). |

## Who owns what

You keep the npm organisation and the package name. You give our release account publish rights, and you can take them away. Your domain and npm organisation are your own costs.

## What isn't included

Changes only your team needs, such as a new adapter or an extra framework binding, are [custom work](https://stratastorage.aoneahsan.com/white-label/custom-work), quoted separately.

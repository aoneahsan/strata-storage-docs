# White-label questions

## Do I get the source code?

You already have it. The repository is public under MIT. The licence adds the rebrand, publishing, docs and releases, and the right to use our name and mark.

## Who owns the npm package name?

You do. The scope sits in your npm account; our release account only holds publish rights, and you can remove them.

## Does it include the Capacitor plugin?

Yes. The rebranded build carries the web adapters, the Capacitor plugin for iOS and Android, and the React, Vue, Angular and Firebase entry points the package ships today.

## Can someone else license the same package?

Yes. A licence isn't exclusive, and there's no buyout because the code is already public.

## Can you add something only we need?

Yes, as [custom work](https://stratastorage.aoneahsan.com/white-label/custom-work), quoted on its own.

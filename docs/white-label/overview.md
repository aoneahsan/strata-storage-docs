# White-label licence

A white-label licence pays us to publish Strata Storage under your npm scope, put your name on these docs, and carry each release over to your package. Your developers still call `set`, `get` and `remove`; the import line changes from `strata-storage` to yours.

## What stays the same

The source is public under the [MIT licence](https://github.com/aoneahsan/strata-storage/blob/main/LICENSE). Anyone can install `strata-storage`, read it and fork it, with or without a licence. Because the code is already open, there's no buyout, and a licence is never exclusive: we can license the same package to other teams.

## What the licence adds

- The managed work: rebrand, publish, docs and releases. [What is delivered](./what-is-delivered.md) lists it.
- The right to say your package is built on Strata Storage and to show our mark beside yours. MIT covers the code, not the name.

## Not the right fit when

- You only need the package. Install `strata-storage`; it's MIT and needs no account.
- You need a hosted backend. Strata Storage keeps values on the device and in the browser, so there's no server for us to run.

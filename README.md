# strata-storage-docs

Documentation site for the [**strata-storage**](https://www.npmjs.com/package/strata-storage) npm package — a zero-dependency universal storage library with one unified async/sync API across web, Android, and iOS.

**Live site:** https://stratastorage-docs.aoneahsan.com

|---|---|
| Package source | https://github.com/aoneahsan/strata-storage |
| npm | https://www.npmjs.com/package/strata-storage |
| Marketing site | https://stratastorage.aoneahsan.com |

This repo contains the site only. Library bugs go to the [package issue tracker](https://github.com/aoneahsan/strata-storage/issues).

It was split out of the package repo (`strata-storage/docs-website` plus the user-facing pages from `strata-storage/docs`) so the docs deploy on their own cadence, matching every other `*-docs` repo in the fleet.

## Run it

```bash
yarn          # install (Yarn 4 / Berry lockfile)
yarn start    # local dev server
yarn build    # production build into build/
yarn serve    # serve the real build
yarn clear    # wipe the Docusaurus cache
```

`yarn build` regenerates `static/llms-full.txt` (`scripts/generate-llms-full.js`) before building. `onBrokenLinks` and `onBrokenMarkdownLinks` are both `throw`, so **the build is the link checker**.

## Layout

```
docs/                     the documentation pages (autogenerated sidebar)
docusaurus.config.js      site config
sidebars.js               autogenerated sidebar declaration
src/css/custom.css        Infima theme variables
static/                   CNAME, robots.txt, llms.txt, images
scripts/                  generate-llms-full.js (runs as part of build)
```

## Deployment

Push to `main` → GitHub Actions (`.github/workflows/deploy-docs.yml`) installs, builds, and publishes `build/` to **GitHub Pages**. The custom domain is pinned by `static/CNAME`, which Docusaurus copies verbatim into `build/`.

Pull requests run the same `build` job without deploying, so it can serve as a required status check.

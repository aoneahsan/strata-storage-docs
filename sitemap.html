  • Introduction

    Strata Storage is a zero-dependency universal storage library with one unified async/sync API across web, Android, and iOS — localStorage, IndexedDB, cookies, Cache API, SQLite, Preferences, and Keychain/Keystore, plus encryption, compression, TTL, querying, and cross-tab sync.

  • Installation

    Install Strata Storage for web, React, Vue, Angular, and Capacitor (iOS/Android) projects. Zero runtime dependencies; framework adapters are optional.

    Get up and running with Strata Storage in five minutes — install, create a storage instance, and run your first get/set/remove operations.

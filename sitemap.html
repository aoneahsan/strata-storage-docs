  • Cache management examples

    A cache is useful only when a miss can be recovered. These examples cache JSON data in a browser adapter and let TTL remove stale entries. Strata's Cache adapter stores JSON-serializable key/value data; it is not the browser's Request/Response cache.

  • Capacitor App Examples

    A Capacitor app can use the same set() and get() calls on web, iOS and Android after it registers the native adapters. A browser build exercises the web adapters; native persistence needs device testing.

  • Compression Examples

    Strata's bundled LZ codec runs when the instance has compression.enabled true option on an unconfigured instance does not initialize the compressor.

  • Configuration Examples

    Use defineStorage() for a web-ready instance. It registers the standard web adapters and initializes on the first operation.

  • Cross-tab change examples

    Strata can notify another browser tab about a change to a supported shared adapter. A notification helps a view refresh; it does not make two concurrent writes atomic or synchronize an authenticated session.

  • Encryption Examples

    Strata uses Web Crypto for encrypted values. Create an instance with encryption enabled, then provide a password at the operation or instance level. A plain defineStorage() instance does not initialize the encryption manager, even if a later set() passes encrypt: true.

  • User Authentication Example

    Strata Storage holds client-side key-value data. It does not authenticate a user, issue a session, or enforce server authorization. The host application must do those jobs. For a browser app, keep the session credential in a server-issued HttpOnly cookie; JavaScript and Strata's cookie adapter cannot create one.

  • Storage adapters

    Strata Storage presents the same key/value operations to different storage backends. The selected adapter determines where values live and which platform can read them.

  • Filesystem Adapter

    Native file-system storage for iOS and Android via Capacitor.

  • Preferences Adapter

    Store small app settings in native iOS and Android preferences through Capacitor.

  • Secure Storage Adapter

    Store sensitive values through Strata Storage's native secure adapter in a Capacitor app.

  • SQLite adapter

    The optional Capacitor SQLite adapter stores Strata key/value records in a native SQLite database on iOS and Android. Strata's public API remains key/value based: it does not expose raw SQL, indexes or atomic SQL transactions through storage.

  • Cache Adapter

    Store Strata key-value data in the browser Cache API.

  • Cookie Adapter

    Store small, non-sensitive values in browser cookies.

  • IndexedDB Adapter

    Store structured key-value data in the browser's IndexedDB database.

  • LocalStorage Adapter

    Persistent browser storage using the localStorage API.

  • Memory adapter

    The memory adapter keeps values in a JavaScript Map. Its values disappear when the page or process is reloaded. Use it for data you can regenerate, short-lived previews and tests.

  • SessionStorage Adapter

    Session-scoped browser storage using the sessionStorage API.

  • URL Adapter

    Persists state in the page URL — shareable, bookmarkable, reload-surviving UI state.

  • Compression API

    Automatic data compression to reduce storage size and optimize performance.
